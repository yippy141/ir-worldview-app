- Old issued Chinese files remain byte-for-byte intact. `foundation-copy-v2.ts` contains nine overrides; exact copy-1 dispatch remains available. Foundation Chinese current copy is 2; other locale/instrument revisions are unchanged.
- The existing tuple of locale, copy revision, question set, bank and scorer identifies the administration. A separate scoring-form ID is unnecessary: item selection/order, response controls, IDs, signals and intended English tasks remain unchanged. Restored Chinese scenario wording is distinguished by copy revision, **not empirically equated**. Core14, baseline56, historical68 and all six targeted forms retain their arithmetic and replay.
- A narrowly additive optional `foundationCopy` field in the existing local draft distinguishes a known single-language/version draft from legacy unknown exposure. The extension type lives outside the frozen issued `lib/types.ts`; storage key and session version stay unchanged. There is no item exposure log, answer history or server field.
- Fresh empty drafts bind when opened. Known copy-1 drafts keep copy 1 through review/reload/extensions. A known draft opened in another language shows a return link or explicitly confirmed restart, with questions withheld. Restart discards that draft's answers and keeps saved results.
- Answered drafts without provenance, including potentially mixed old exposure, retain old wording. Completion uses the existing unknown-copy value **0**, and cannot mint answer-wording evidence. Unsupported future draft revisions are withheld. No historical language exposure is inferred.
- Shared/saved results keep their original scores, identity and recorded provenance. Existing answer evidence is read from the stored bound record, never regenerated from current wording. New evidence checks the exact payload/copy tuple; stale or mismatched bindings remain unavailable.
- Existing Tier 1 collection remains unactivated. Its unchanged validator accepts only current copy: historical/unknown copy cohorts are rejected, rather than relabeled as current. Call sites supply the truthful existing copy field; no API or collection schema is expanded.
