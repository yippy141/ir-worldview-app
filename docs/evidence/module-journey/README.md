## Exact evidence-selection semantics

The unchanged `buildModuleDecisiveCalls` helper sorts primary-option signals by `abs(value - 4)`. Rank equals the strongest recognized axis distance plus `0.35 ×` the second signal distance, plus `0.15` for actor-lens cards in the historical full-analysis selection. Stable ties follow existing signal/question order. It retains at most six calls. This measures directional salience, not marginal contribution; secondary answers and scorer question/lane weights do not determine rank.

The opening applies this helper to Explanation/Decision selections and displays the first two, including any corresponding secondary answer. Actor-lens selections are excluded because both registered runtimes exclude them from the main score. The original full-analysis selection remains intact. The literal heading is **Choices behind this reading**.

Partial, empty and actor-only records retain existing computed output. Missing scored answers receive an explicit explanation without an invented transcript or empty grid.
