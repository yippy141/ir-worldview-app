# The Departure: draft 0.1

The first working English journey is `/futures/departure`. Its three comparisons separate a desired arrangement, the credibility of claimed protections, personal decisions, other adults’ permission to leave, and public authorization of monitoring and intervention. There is no aggregate score or scenario match.

## Inspect the draft

Run from the implementation worktree:

```sh
npm run build
npm run start -- --hostname 127.0.0.1 --port 3107
```

Open [the local draft](http://127.0.0.1:3107/futures/departure). The route has a dated draft label and `noindex, nofollow` metadata. A production-domain URL will not exist until separately published. This delivery neither deploys nor merges.

Personal framing is the owner-selected default. The policy framing considers a fictional adult, with the same available decisions. Answers live only in React component memory. Returning to the story or using its shelf anchor preserves them; leaving/reloading discards them. Framing changes and clearing a draft require an inline confirmation. No account, research intake, answer API, URL payload or demographic inference is introduced.

## Walkthrough

1. Read the invitation and choose a framing. Earth keeps the shared tools and self-government; return remains unknown.
2. Comparison A asks separately about the trusted arrangement, needed evidence, personal decision and reason, and other competent adults’ freedom to leave.
3. Comparison B adds lifetime return-service provision, communication with travel-related delays and exit without AI permission. Only its preference question stipulates that these protections work. Credibility and personal decisions retain uncertainty.
4. Comparison C compares no veto, a jointly reviewed compact and a unilateral indefinite ban. Monitoring and intervention authority are separate responses.
5. Review all thirteen choices, then explicitly submit. A sample path of staying initially, allowing others to go, and leaving under revised return terms produces a condition-specific reading. Reasons are quoted back rather than inferred. An earlier edit clears later responses and the old reading.
6. Read the political continuation and browse Gatekeeper, Protector God and the outline of Constitutional Delegation. No single axis or probability ranks them.

## Scientific and institutional assumptions

The medical and material achievements, feasible biological travel and habitable settlements are fictional stipulations. No propulsion method, travel duration, destination property claim or reunion guarantee is established. Uploading, copying and other-dimensional travel are out of this case’s scope. Return-service provision is a trusted premise only when explicitly declared; enforcement against a vastly more powerful system remains an open problem elsewhere.

The output does not collect expected likelihood or a time horizon, so it cannot infer plausibility from desire. It records acceptance despite objections separately from welcoming an arrangement. “None of these” is a refusal of the supplied categories, not missing psychological data to fill in.

AI Governance results link to the journey without pre-answering it or carrying a payload. No result-history import was needed for the complete standalone experience. Any later saved record, matching model or research intake requires a separate decision.
