# Foundation 简体中文改编测试版观察事项

Owner approval 采用当前裁决作为改编测试版文案，并允许运行时接入。本清单改为发布后的认知访谈与编辑观察项，不再是 beta 发布阻断项。它不会被用来宣称与英文版等价，也不会授权合并两种语言的数据。

| ID | 事项 | 当前建议 | 仍需证据或决定 |
|---|---|---|---|
| FZH-01 | `balance of power` 的公开题项用语 | 正文用“实力对比”，解释材料可用“权力均势／权力格局” | 认知访谈确认“实力对比”不会被缩成中美双边综合国力排名 |
| FZH-02 | `institution` 的分流规则 | 规则体系用“国际制度”，具体组织用“国际机构”，组合体用“制度安排” | 中文编辑批准分流规则，并逐题确认无概念漂移 |
| FZH-03 | `legitimacy` 的核心译法 | 规范接受用“正当性”，法律资格用“合法性／法律效力” | 检查不同地区读者是否把“正当性”理解为道德正确性而非被接受的权威 |
| FZH-04 | `restraint` 的表现方式 | 不设单一机械对应；按题项写“控制承诺范围”“避免战略透支”或“限制行动边界” | 方法负责人确认不同表达仍指向同一 restraint 维度，而非引入新构念 |
| FZH-05 | `order` 与 `justice` 的语境拆分 | order 在规则语境用“国际秩序”，在最低稳定语境展开；justice 按“正义／纠正不公／追责”分流 | 核对 `oj1`、干预题与停战题是否仍可比较，而不要求文字表面完全一致 |
| FZH-06 | `deterrence` | 一般机制用“威慑”，承诺可信问题用“威慑可信度” | `an_case_burdens` 与 `an_case_maritime_crisis` 访谈确认读者没有把威慑等同于升级 |
| FZH-07 | `hedging` | 首次写“战略对冲”，并在选项正文展开风险分散与保留回旋 | 测试“对冲”是否仍被主要理解为金融操作或机会主义 |
| FZH-08 | `solidarity` | 不统一写“团结”；按共同承担、相互支持或共同维护规则处理 | 等待 normative modifier 与 Foundation 结果中文内容一并裁决 |
| FZH-09 | Likert 中点标签 | 拟用“既不同意也不反对”，不用“中立” | 访谈区分无意见、证据不足、条件性判断和真正中点；决定 UI 是否需要补充说明 |
| FZH-10 | `sc1` 与 `ni1` 的“更重要／更难稳固”强度 | 保留英文比较方向 | 检查中文受访者是否因绝对比较而回避端点 |
| FZH-11 | `rs1` 的规范性暗示 | 当前“超出自卫所需”忠实保留，但可能预设额外收益不必要 | 认知访谈判断不同意端是否被听成主张侵略；必要时重写整题而不动评分 |
| FZH-12 | `oj1` 的社会赞许风险 | 当前用“重大不公”与“稳定的国际秩序” | 测试同意端是否被读成漠视不公；若是，需在不弱化构念的前提下平衡措辞 |
| FZH-13 | 干预题中的主权表达 | `oj2` 用“突破通常享有的主权保护” | 法律与中文编辑确认该表述不暗示永久取消主权，也不预先赞同行动 |
| FZH-14 | `mandate` 与 `authorization` | 分别用“行动授权”与“正式授权” | 检查一般读者能否理解授权来源与行动范围的区别 |
| FZH-15 | `tradeoff_interdependence.rules` | “维持开放、降低受胁迫风险”可能成为明显折中项 | 轮换选项顺序并追问第二选择；若中庸吸引持续，需回到英文源题共同审查，而非只改中文 |
| FZH-16 | `case_semiconductors.coalition` | “与盟友精准设限”可能比其他选项更专业、温和 | 认知访谈检查“精准”是否成为无条件正面词；可考虑“协调范围有限的管制” |
| FZH-17 | `case_protection.bounded` | “有限的紧急正当性”语义准确但明显折中 | 检查受访者是否因组合了地区支持和限制条件而默认选择，而非真正认为该逻辑居首 |
| FZH-18 | `an_case_finance.pragmatic` | 混合成因项极易吸引中间回答 | 判断是否为英文源题本身的结构风险；中文不得单方面强化或弱化该项 |
| FZH-19 | `an_case_middle_power` 的行为体名称 | 采用“中等力量国家”，暂不使用“中等强国” | 不同地区政策读者访谈确认该词自然且不含贬义 |
| FZH-20 | `an_case_green_finance` 的国家描述 | 采用“较低收入国家”，避免固定身份标签 | 确认不削弱该国财政与谈判约束，也不产生居高临下语气 |
| FZH-21 | `digital stack` 与 `interoperability` | 保留“数字技术栈”“互操作性”，首次出现附解释 | 新读者必须能在不依赖英文的情况下复述；否则改为正文解释、术语退居括注 |
| FZH-22 | `securitization` | 标题保留“安全化”，正文解释“定义为安全危机” | 确认不会被误读为证券化或一般网络安全强化 |
| FZH-23 | `investment screening` | 采用“投资安全审查” | 政策编辑确认是否需写“外资安全审查”；两者在部分语境的范围不同 |
| FZH-24 | `post-colonial government` | 面向一般读者写“有殖民经历的国家” | 专业编辑确认未丢失后殖民国家位置所包含的持续权力关系 |
| FZH-25 | 第二选择的中文说明 | 主选择外的“第二顺位判断”仍按英文 45% 权重处理；中文只说明权重较低，不显示数值 | UI 走查确认中文不暗示第二选择是同等认可；不得改动 `SECOND_CHOICE_WEIGHT` |
| FZH-26 | Standard 五个部分标题 | 当前拟为“国际关系判断基线／同盟与相互依存／国内政治与身份／战略与价值取舍／应用情境” | 在 390px 下检查换行，并确认标题不提示评分维度 |
| FZH-27 | 题项中的“本国／你的国家”视角 | 当前仅在英文使用 `your` 时译为“本国”，actor-lens 题继续要求代入指定国家 | 检查受访者是否自动代入中国，导致一般判断变成国别政策态度 |
| FZH-28 | 标点与引号 | 中文正文使用全角标点，术语解释不用英文引号；ID 保持 ASCII | 完成最终 UI、复核页、打印与 390px 截图后裁决 |

## 明确不在本批次解决

- 不改评分方向、权重、维度或 family profile；
- 不改变 Standard 与 Analyst 题目数量、顺序或第二选择权重；
- 不改变本地草稿、复核页编辑、生成结果和重新开始行为；
- 不把认知访谈结果表述为心理测量验证；
- 不把 beta approval 表述为心理测量验证或跨语言等价性结论。
