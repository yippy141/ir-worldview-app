## Owner note on typography direction

The production brief contains two signals that should be recorded without
reopening the selected product direction:

1. The implementation requirement locks Spectral for editorial text and Libre
   Franklin for interface and body text, with the existing Chinese Songti and
   PingFang-compatible fallbacks.
2. The owner separately noted a marginal preference for typography treatment
   C from the evidence study.

This candidate follows the explicit Spectral and Libre Franklin requirement.
The preference for C is reflected only in restraint, scale, and composition,
not as permission to substitute a different font system. The owner should
confirm whether that interpretation is correct before release.
